# LeadFlow

Lead generation and customer retention SaaS.

## Features

- Lead import and management
- Campaigns and email templates
- Workflow builder and integrations
- Analytics

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/converza-hub.git
cd converza-hub
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
